# Legacy Artifact Policy

The active product is `V3_Epistemic/output/reliable_influence_map.html` with
data generated by `V3_Epistemic/pipeline/`.

Legacy/reference-only locations:

- `_archive/`
- `V3_Epistemic/output/dc_epistemic_map_mvp.html`
- old prompt and rescue notes at the repository root
- `V3_Epistemic/processed/`
- legacy frontend files that are not loaded by `reliable_influence_map.html`

Do not revive the archived React app in this rescue pass. Do not use legacy
payloads to make current analytical claims. If a legacy file is useful as a
reference, copy only the verified idea into the active pipeline or docs and note
the current source file that supports it.
