# Interpretation Guide

Read the map as an evidence-weighted relationship view.

- Observed fields come directly from raw exports or corrected source snapshots.
- Derived fields are deterministic transformations, joins, rollups, or graph
  metrics.
- Modeled fields are analytical outputs such as embeddings, communities, and gap
  leads.

Node size uses observed spend or filing volume where available. Government nodes
use target-side lobbying exposure, not agency spending. Color is a selected lens.
Round markers are used for all entity types; letters identify firm, client,
lobbyist, government, and reference nodes.

The first screen is a capped 2D issue-space scene for browser performance. The
full graph remains searchable through the index payload. The 3D view stacks the
same coordinates by year.

Revolving-door arcs represent resolved career-transition records. Unknown
transition years stay unknown and are shown only in the selected context.

2025 is partial unless refreshed source exports and validation reports say
otherwise.
