# Data Dictionary: Frontend Payloads

This file describes the frontend payloads generated by `V3_Epistemic/pipeline/09_build_reliable_payload.py`. The active map loads `scene_payload.json` for first paint and `search_index.json` for full search/detail lookup. `reliable_visual_payload.json` remains available as a legacy-compatible aggregate export.

## Top-Level Fields

| Field | Type | Units | Description | Known gaps |
| --- | --- | --- | --- | --- |
| `meta` | object | n/a | Dataset metadata, quality notes, performance caps, and visual encoding contract. | Depends on successful pipeline generation. |
| `entities` | array<object> | rows | Cleaned actor and reference-node records used by the 3D scene. | Initial visibility is capped for performance. |
| `entity_years` | array<object> | rows | Entity-year rendering records for active years and display sizing. | Often aggregate repeated, not observed entity-year spend. |
| `edges` | array<object> | rows | Deduplicated relationship graph edges. | Payload may include only top edges by weight. |
| `clusters` | array<object> | rows | Community/cluster summaries from the processed layout graph. | Cluster labels are derived. |
| `gap_grid` | object | grid cells | Model-derived gap lead texture and top-gap summaries. | Analytical signal, not direct observation. |
| `revolving_vectors` | array<object> | rows | Aggregate revolving-door flow vectors. | Transition years may be estimated. |
| `topics` | object | lists | Text/topic support layer. | Narrative context only, not primary scoring. |

## `meta`

| Field | Type | Units | Description | Known gaps |
| --- | --- | --- | --- | --- |
| `years` | array<number> | years | Included visual years, currently 2018-2025. | Update through `config.py` when source range changes. |
| `partial_years` | array<number> | years | Years treated as incomplete, currently 2025. | Requires source metadata to remove partial flag. |
| `source_snapshot` | string | date/text | Source snapshot or latest source year. | Falls back to `latestYear` when date is unavailable. |
| `generated_at` | string | date/text | Generation/snapshot marker used by the frontend badge/copy. | Same limitation as `source_snapshot`. |
| `data_quality_summary.issue_count` | number | count | Count of known data quality issues. | Only captures checks implemented in pipeline. |
| `data_quality_summary.high_severity_issues` | number | count | Count of high-severity issues. | Same as above. |
| `data_quality_summary.missing_value_policy` | array<string> | n/a | Values treated as missing in audits. | Depends on audit rule coverage. |
| `data_issues` | array<object> | rows | Detailed unresolved quality flags. | Some flags require human review. |
| `edges_truncated` | boolean | n/a | Whether the edge payload is capped. | Frontend displays disclosure. |
| `total_edges_in_data` | number | count | Total eligible edges before payload cap. | Eligibility depends on visible entity cap. |
| `performance_caps` | object | n/a | Entity/edge/arc rendering caps. | Browser-dependent. |
| `visual_encoding` | object | n/a | Contract for axes, color, shape, size, opacity, halo, and gaps. | Must stay aligned with frontend code. |

## `entities[]`

| Field | Type | Units | Description | Known gaps |
| --- | --- | --- | --- | --- |
| `id` | string | n/a | Stable canonical entity ID. | Hash IDs are opaque by design. |
| `name` | string | n/a | Display name. | May inherit source casing/noise. |
| `entity_type` | string | category | `firm`, `client`, `lobbyist`, `gov_agency`, or `reference_node`. | Some external endpoints may be unresolved. |
| `entity_subtype` | string | category | More specific subtype/classification. | Client subtype can be inferred. |
| `primary_policy_category` | string | category | Rollup policy category from issue profiles. | `Unknown` when issue evidence is missing. |
| `region` | string | category | U.S. region or `DC`/`Unknown`. | Missing client state reduces accuracy. |
| `state` | string | state code | Source state where available. | Often missing for clients/lobbyists. |
| `active_years` | array<number> | years | Years with direct or assumed activity. | Lobbyist/gov agency years may be aggregate/assumed. |
| `x` | number | normalized coordinate | UMAP or inferred issue-space x coordinate. | Inferred coordinates are flagged. |
| `y` | number | normalized coordinate | UMAP or inferred issue-space y coordinate. | Inferred coordinates are flagged. |
| `z_semantics` | string | n/a | Meaning of vertical axis, usually `year`. | Static contract. |
| `coordinate_source` | string | category | `legacy_umap`, `neighbor_inferred`, or deterministic fallback. | Low-confidence placement may appear on ring. |
| `cluster_id` | string/number | id | Community ID. | Empty when cluster missing. |
| `cluster_label` | string | category | Derived cluster label. | May mirror policy category. |
| `top_issue_code` | string | issue code | Dominant LDA issue code. | Empty when issue evidence missing. |
| `top_issue_label` | string | issue label | Human-readable issue label. | Raw codes with no mapping fall back to code. |
| `metrics.observed_spend` | number/null | USD | Observed spend/income for firms/clients where valid. | Null for government agencies and reference nodes. |
| `metrics.target_attention_exposure` | number | USD-like exposure | Raw target-side exposure where relevant. | Not additive spend. |
| `metrics.lobbying_exposure` | number/null | USD-like exposure | Government lobbying exposure used for government node size. | Only meaningful for `gov_agency`. |
| `metrics.filings_total` | number | count | Total filing count. | Source coverage varies. |
| `metrics.influence_score` | number | 0-1 score | Evidence-weighted prominence score. | Derived and sensitive to missing fields. |
| `metrics.momentum_score` | number | 0-1 score | Recent activity/category trend score. | Not observed year-by-year spend. |
| `metrics.revolving_door_score` | number | 0-1 score | Revolving-door intensity. | Transition dates may be estimated. |
| `metrics.concentration_score` | number | 0-1 score | Firm/client/issue concentration signal. | More complete for firms. |
| `metrics.gap_score` | number | 0-1 score | Model-derived gap lead intensity. | Not a direct fact. |
| `metrics.node_size_metric` | string | category | Metric used for visual node size. | Government uses exposure, not spend. |
| `metrics.node_size_value` | number | log scale | Precomputed log-scaled size value. | Capped by frontend radius. |
| `confidence.score` | number | 0-1 score | Evidence completeness/confidence score. | Heuristic. |
| `confidence.level` | string | category | `high`, `medium`, `low`, or fallback `unknown`. | Heuristic. |
| `confidence.flags` | array<string> | flags | Quality/provenance flags. | Requires user-visible interpretation. |
| `source_files` | string | filenames | Semicolon-separated evidence sources. | Not row-level citation. |
| `default_visible` | boolean | n/a | Whether entity appears in initial scene. | Performance cap, not data exclusion. |

## `entity_years[]`

| Field | Type | Units | Description | Known gaps |
| --- | --- | --- | --- | --- |
| `entity_id` | string | n/a | Links to `entities[].id`. | Must match payload entity. |
| `year` | number | year | Visual year slice. | 2026 excluded. |
| `active` | string/boolean | n/a | Whether entity is active in this slice. | String form may be used for CSV compatibility. |
| `active_year_basis` | string | category | Source/rule for active-year assignment. | `unknown_repeated` means weak temporal evidence. |
| `observed_spend` | number/null | USD | Observed spend if active and valid. | Null for government/reference nodes. |
| `lobbying_exposure` | number/null | USD-like exposure | Government exposure if active. | Not spend. |
| `filings_total` | number | count | Filing count repeated to active year row. | Not necessarily year-specific. |
| `display_size_metric` | string | category | Visual size metric for this row. | Use with provenance. |
| `display_size_value` | number | log scale | Visual size value for this row. | Aggregate repeated unless flagged otherwise. |
| `temporal_value_type` | string | category | `aggregate_repeated`, `unknown_repeated`, or future observed type. | Current data often repeated. |
| `is_partial_year` | string/boolean | n/a | Whether the year is partial. | Current partial year is 2025. |

## `edges[]`

| Field | Type | Units | Description | Known gaps |
| --- | --- | --- | --- | --- |
| `source_id` | string | n/a | Source entity ID. | Skipped in frontend if missing. |
| `source_name` | string | n/a | Source display name. | For inspection only. |
| `target_id` | string | n/a | Target entity ID. | Skipped in frontend if missing. |
| `target_name` | string | n/a | Target display name. | For inspection only. |
| `edge_type` | string | category | Relationship type. | Must not mix spend/exposure semantics. |
| `weight` | number | normalized/log/count | Rendering and ranking weight. | Semantics vary by edge type. |
| `raw_value` | number | source units | Raw source value when available. | May be 0 for count edges. |
| `measure_type` | string | category | Meaning of `raw_value`/`weight`. | See edge type. |
| `source_files` | string | filenames | Evidence files. | Not row-level citation. |
| `confidence` | number | 0-1 score | Edge resolution confidence. | Heuristic. |
| `resolution` | string | category | Entity resolution method. | Fuzzy/external endpoints require review. |
| `duplicate_count` | number | count | Number of duplicate triples aggregated. | Higher values can indicate source repetition. |
| `is_self_edge` | string/boolean | n/a | Whether source and target are same entity. | Should be flagged or separated. |

## `clusters[]`

| Field | Type | Units | Description | Known gaps |
| --- | --- | --- | --- | --- |
| `cluster_id` | number/string | id | Community ID. | Depends on graph layout. |
| `label` | string | category | Derived cluster label. | Human review recommended. |
| `member_count` | number | count | Entities in cluster. | Based on processed graph. |
| `total_spending` | number | USD | Firm-only cluster spend aggregate. | Excludes government exposure. |
| `total_lobbying_exposure` | number | USD-like exposure | Government exposure aggregate. | Separate from spend. |
| `centroid_x` | number | coordinate | Cluster x centroid. | Derived. |
| `centroid_y` | number | coordinate | Cluster y centroid. | Derived. |
| `entity_types` | object | counts | Entity-type distribution. | Depends on visible processed members. |

## `gap_grid`

| Field | Type | Units | Description | Known gaps |
| --- | --- | --- | --- | --- |
| `grid_size` | number | cells | Width/height of square grid. | Usually 80. |
| `gap_score` | array<array<number>> | 0-1 score | Model-derived heat texture. | Use as analytical lead only. |
| `top_gaps` | array<object> | rows | Highest gap cells/areas. | Derived and confidence-weighted. |
| `semantics` | string | n/a | Explicit caveat that gaps are model-derived. | Static contract. |

## `revolving_vectors[]`

| Field | Type | Units | Description | Known gaps |
| --- | --- | --- | --- | --- |
| `src_x`, `src_y` | number | coordinate | Vector start in issue-space. | Derived from source entity placement. |
| `tgt_x`, `tgt_y` | number | coordinate | Vector end in issue-space. | Derived from target entity placement. |
| `magnitude` | number | count/log-like | Flow intensity. | Counts transition events, not people. |
| `transition_year` | number | year | Observed or representative transition year. | Often estimated as representative year. |
| `transition_year_estimated` | boolean | n/a | Whether transition year was estimated. | True when raw positions have no date. |
| `temporal_scope` | string | category | Observed or estimated transition-year semantics. | Aggregate if exact dates absent. |
