# Code of Conduct

This project follows a simple standard: keep discussion factual, respectful,
evidence-based, and focused on improving the software, data lineage, and public
interpretation.

Do not use this repository to target private individuals, imply wrongdoing not
supported by source evidence, publish private information, or harass
contributors or named public-record subjects.

The repository owner may remove comments, issues, or contributions that violate
these expectations.
